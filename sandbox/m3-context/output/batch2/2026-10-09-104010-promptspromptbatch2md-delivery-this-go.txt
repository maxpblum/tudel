  - skills.yaml: the unit and skill entries to add.
  - glossary/chord-symbols.yaml: 10 new symbols, such as Am9, Em9, G6 and Ab^7.
    It also lists existing symbols so the ingest step merges their skill lists.
    I spelled the tones myself because the local tonal package wouldn't load.
  - VERIFIED_FACTS.md: what I checked in the pinned Strudel source:
    - pw sets the pulse's duty cycle as (1 − pw) / 2, so the default 0.5 is
      already a 25 % pulse.
    - tremolosync's default shape rises through each beat, which gives a
      ready-made pump.
    - duckattack is actually the recovery time.
    - Strudel has no noise gate, so the gated snare is described as an
      approximation.
