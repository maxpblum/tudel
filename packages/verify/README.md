# @tudel/verify

The verification package: the Node-only gate that all content must pass to enter the app (PROPOSAL §7, §13). It loads `content/`, runs gates L0-L5, L7 and L8, and, only if all pass, compiles the bundle the app reads (`apps/web/src/content/bundle.json`, schema `Bundle` in `@tudel/content-schema`).

The bundle is `schemaVersion` 2. Besides units, skills, lessons, variants and the timbre lexicon, it carries `chords` (copied from `content/glossary/chord-symbols.yaml`, empty if the file is absent; L0 checks each entry's `skills` exist) and `terms` (derived in `src/compile/terms.ts`: one per name in any skill's `vocabulary`, with the first sentence of its doc.json description and every skill that lists it).

What each gate checks and how to work with them: [docs/verification.md](../../docs/verification.md).

## Commands

```sh
pnpm verify                      # from the repo root: all gates, bundle on success
pnpm verify --update             # also rewrite L3 snapshots (__snapshots__/), then review the diff
pnpm verify --explain <id>       # per-gate report for one variant or lesson
pnpm --filter @tudel/verify test # unit tests (Vitest)
pnpm --filter @tudel/verify typecheck
node scripts/run.mjs eval 'note("c3 e3").s("sawtooth")' 2   # dev tool: print the haps of a snippet
pnpm --filter @tudel/verify sounds   # regenerate tools/strudel-ref/sounds.json (network)
```

## Why everything runs through esbuild

Plain Node and Vite can't load `@strudel/core` and the `@tonaljs/*` packages at the pinned versions (broken `main` entries). `scripts/run.mjs <entry>` bundles `src/bin/<entry>.ts` with esbuild (`mainFields: ['module', 'main']`) into `.cache/` and runs it. Tests use the same trick at two seam modules (`src/harness/strudel-deps.ts`, `src/harness/music-deps.ts`), which `vitest.config.ts` bundles and aliases. **Never import `@strudel/*` or `tonal` anywhere else.** See [ADR 0002](../../docs/decisions/0002-esbuild-bundled-harness.md).

## Layout

| Path | Contents |
|---|---|
| `scripts/run.mjs` | esbuild-bundle-and-run wrapper for `src/bin/*` |
| `src/` | The verifier ([src/README.md](src/README.md)) |
| `__snapshots__/` | Committed L3 golden files, one `<id>.snap` per variant or lesson. Generated by `--update`; never hand-edit |
| `test/` | Vitest suites, one per gate plus the compiler and the CLI ([test/README.md](test/README.md)) |
| `vitest.config.ts` | Bundles the seam modules before tests run |
